PWA Icon Placeholder

To complete the PWA setup, add the following icon files to this directory:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

These icons should:
- Be square images
- Have a transparent or themed background
- Feature the FitCoach logo (dumbbell icon works well)

You can generate these icons from a single 512x512 source image using:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
